# 语料来源政策

核心语料是从固定 Git commit 的 Kanseki Repository《史记》《资治通鉴》生成的简体转写本。本地不保留上游繁体正文文件，也不保留 OpenCC 包、配置或字典。刷新语料时按固定 URL 临时下载 `opencc-python-reimplemented 0.1.7` wheel，先核对 SHA-256，再用 `t2s` 配置转换；完成文件数、行数与哈希验证后清除 wheel、解压内容和上游临时文件。

`manifest.json` 必须保存上游仓库、commit、原始文件字节数与 SHA-256、简体文件字节数与 SHA-256、对应行数、OpenCC 版本、配置和 wheel SHA-256。简体文件与上游文件保持同名、同行号；由于繁简转换可能合并异体字或一对多字形，简体转写不得称为上游原文字形。

Kanseki Repository 的 GitHub 组织资料声明其综合古籍语料采用 CC BY-SA 4.0。两个具体仓库当前没有 GitHub 可识别的 SPDX 许可字段，因此清单必须同时记录许可依据 URL 和这一限定，不得把仓库级许可状态描述得比上游资料更确定。

中文维基文库只作人工抽样旁证，不进入核心语料。发生文本差异时并列说明，不自行定本。任何无法由本地简体文件逐字校验器通过的引文不得作为证据。
