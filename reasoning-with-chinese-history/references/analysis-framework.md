# 决策结构分析框架

## 现实决策卡

先提取以下字段，不要先找“像谁”的故事：

| 字段 | 要回答的问题 |
|---|---|
| 决策者 | 谁承担选择和后果？权限、责任、资源是什么？ |
| 真实目标 | 想获得什么？哪些底线不能交换？ |
| 事实与未知 | 哪些已经证实？哪些只是他人陈述、预测或猜测？ |
| 可选行动 | 除了接受/拒绝，是否有延迟、试探、分阶段、谈判或退出？ |
| 时间 | 截止时间是真实约束还是施压手段？等待会损失什么？ |
| 激励 | 各方希望你做什么，他们分别获得什么？ |
| 权力差 | 谁能改规则、扣留信息、转嫁损失或安全退出？ |
| 可逆性 | 哪些选择可撤销？沉没成本和锁定点在哪里？ |
| 尾部风险 | 最坏后果是什么，发生概率未知时能否承受？ |
| 制度伦理 | 合同、职责、声誉、关系与道德边界是什么？ |
| 路径依赖 | 这一步会打开或关闭哪些未来选项？ |

缺少会实质反转结论的信息时，只问一个最关键问题。其余未知项以清晰假设表示。

## 案例相似性

逐项比较，而不是给一个伪精确总分：

- 权力位置和行动空间是否相似；
- 目标与底线是否相似；
- 信息不完全和时间压力是否相似；
- 合作者、对手及旁观者的激励是否相似；
- 可逆性、最坏后果和承受能力是否相似；
- 制度、伦理和时代条件是否相似；
- 短期收益是否会制造长期锁定。

表面事件一致但结构不同的案例应淘汰。例如同为“跳槽”，受胁迫的政治投奔与拥有合同保护的现代就业并不天然相似。

## 历史案例重建

每个案例分别写：

1. 当时处境与当事人已知信息；
2. 当时可见选项，不把后见之明塞回过去；
3. 实际选择及史料明示的理由；
4. 立即结果和长期结果；
5. 显性代价；
6. 隐性代价、机会成本和路径锁定；
7. 未走路线及证据限制；
8. 与现实场景的相似点和决定性差异。

## 证据标签

- `史料事实`：本地原文直接支持的事件、言论或结果。
- `现代释义`：对原文的白话解释，不得放进原文引号。
- `分析解释`：对激励、机制和代价的现代分析。
- `推断`：动机、反事实和未选择路线的合理重建；必须说明依据和不确定性。

成功不证明当时判断正确，失败也不自动证明判断错误。必须结合当时信息、可选路线、风险暴露和运气评价决策质量。

## 常见偏差

- 结果偏见：用最终成败替代事前判断。
- 幸存者偏差：只看留下记录的赢家。
- 人物神化：把复杂结果归为性格或一句格言。
- 单案例过拟合：忽略反例和制度差异。
- 道德漂白：把欺骗、暴力、胁迫或歧视包装成通用策略。
- 时代错置：把君臣、宗族、战争中的强制关系直接套入现代生活。
